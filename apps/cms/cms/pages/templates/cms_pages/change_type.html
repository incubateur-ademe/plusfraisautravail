Type actuel : {{ page.specific_verbose_name }}. La page garde son adresse, sa place dans l'arborescence et son historique. Les champs communs aux deux types (titre, en-tête, contenu, mots-clés…) sont conservés.

Le changement est impossible dans les cas suivants :

  • Modifications en brouillon : la page est publiée et a des modifications non publiées. Publiez-les ou annulez-les d'abord.
  • Sous-pages incompatibles : un type n'est proposé que s'il accepte toutes les sous-pages actuelles. Déplacez-les d'abord, par exemple pour transformer une page qui a des enfants en article de blog, qui n'en accepte aucun.
  • Type unique déjà utilisé : les types limités en nombre (page d'accueil…) ne sont plus proposés une fois la limite atteinte.
  • Type non créable : les types qu'on ne peut pas créer dans l'admin ne sont pas proposés.
  • Type à structure particulière : seuls les types stockés directement sur la page Wagtail de base peuvent être échangés. Si la page actuelle n'en fait pas partie, aucun type n'est proposé.
  • Contenu lié qui bloque la suppression : un élément rattaché à l'ancien type empêche de le retirer (le message d'erreur indique lequel).
  • Page invalide pour le nouveau type : un champ obligatoire du nouveau type est vide, ou une question FAQ cochée « SEO » l'est déjà sur une autre page. Rien n'est modifié et l'erreur s'affiche ici.
  • Droits insuffisants : il faut pouvoir publier la page. Sinon le bouton n'apparaît pas.

Si l'emplacement actuel n'accepte pas le nouveau type (un article de blog transformé en page de contenu, par exemple), le changement est quand même fait. Vous êtes ensuite envoyé sur l'écran de déplacement pour choisir où ranger la page.
